# Introduction

Amazon Bedrock AgentCore is a platform to build, deploy and operate agents


## [AgentCore gateway](agentcore-gateway.md)

Convert APIs, Lambda functions, and existing services into Model Context Protocol (MCP)-compatible tools and make them available to agents


## [AgentCore memory](agentcore-memory.md)

A simple and powerful way to handle both short-term context and long-term knowledge retention


## [AgentCore runtime](agentcore-runtime.md)

A secure, serverless and purpose-built hosting environment for deploying and running AI agents or tools


## [AgentCore identity](agentcore-identity.md)

Secure authentication, authorization, and credential management capabilities that enable agents and tools to access AWS resources and third-party services on behalf of users while helping to maintain strict security controls and audit trails


## [AgentCore observability](agentcore-observability.md)

Trace, debug, and monitor agent performance


## [AgentCore code interpreter](agentcore-code-interpreter.md)

Enables AI agents to write and execute code securely in sandbox environments


## [AgentCore browser tool](agentcore-browser-tool.md)

A secure, cloud-based browser that enables AI agents to interact with websites
