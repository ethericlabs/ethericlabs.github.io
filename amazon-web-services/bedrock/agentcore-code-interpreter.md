# Overview

Agents write and execute code securely in sandbox environments by invoking a large language model which selects tools and creates a session

The code interpreter session provides

- code interpreter
- shell
- file system
- telemetry

Supported languages

- Python
- JavaScript
- TypeScript

The result is available to agents
