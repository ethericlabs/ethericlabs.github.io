# Summary

An overview of Bedrock AgentCore browser tool


# References

Interact with web applications using Amazon Bedrock AgentCore Browser

# Overview

Agents browse securely in an isolated environment by invoking a large language model which selects tools

Tool commands are translated to browser commands

- Playwright
- Browser_use

Browser commands are used to control an isolated browser

A screenshot is available to agents
