# Overview

Bedrock Observability uses AWS CloudWatch and telemetry features to measure agents, gateways & memory by default

- session count
- latency
- duration
- token use
- error rate

to help 

- Trace agents
- Debug agents
- Monitor agents
- Detailed agent workflow visualisations

OpenTelemetry (OTEL) compatible data can be generated
